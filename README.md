# Triply ✈ Travel Planner & Bill Splitter

**Plan · Travel · Together**

แอปวางแผนเที่ยวและหารค่าใช้จ่ายกับเพื่อน โทนเขียวป่า-ครีม ภาพประกอบภูเขา ทะเลสาบ ฟอนต์ Mali ติดตั้งลงมือถือได้ (PWA) ใช้ออฟไลน์ได้ รองรับภาษาไทยและญี่ปุ่น

## ฟีเจอร์
- **Dashboard** — ยอดใช้จ่ายรวม งบคงเหลือ (เกจแบบน้ำ) ใครจ่ายไปเท่าไหร่ ยอดที่ต้องเคลียร์ กิจกรรมล่าสุด
- **Next Plan** — ทริปถัดไปแบบบอร์ดดิ้งพาส กำหนดการรายวัน ยอดประมาณเทียบยอดจ่ายจริงของแต่ละสถานที่
- **Trip Expense** — จ่ายเอง / หารกับเพื่อน หารเท่ากัน กำหนดยอด หรือเป็น % คำนวณเป็นหน่วยสตางค์ ไม่มีเศษเพี้ยน หักกลบให้โอนน้อยครั้งที่สุด บันทึกและยกเลิกการโอนได้
- **Travel Receipt** — สลิป 3 สไตล์ (Kawaii Café, Travel Journal, Pastel Ticket) ภาษาไทย ญี่ปุ่น หรือสองภาษา บันทึกเป็น PNG / PDF หรือแชร์
- **ภาษา** — สลับ UI ไทย / 日本語 และเปิดแสดงภาษาที่สองคู่กันได้

## ติดตั้งบนมือถือ
เปิดเว็บของ repo นี้ (GitHub Pages) แล้ว
- **iPhone (Safari):** ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
- **Android (Chrome):** กด "ติดตั้ง" ในแอป หรือเมนู ⋮ → ติดตั้งแอป

## เปิด GitHub Pages (ครั้งแรกครั้งเดียว)
Settings → Pages → Source: **GitHub Actions** จากนั้นทุกครั้งที่ push เข้า `main` เว็บจะอัปเดตเอง

## โครงสร้าง
```
index.html             แอปทั้งตัว (HTML/CSS/JS ไฟล์เดียว, ไม่ต้อง build)
manifest.webmanifest   ข้อมูลแอปสำหรับติดตั้ง
sw.js                  service worker สำหรับใช้ออฟไลน์
vendor/                html2canvas 1.4.1, jsPDF 2.5.1
icons/                 ไอคอนแอป
fonts/                 ฟอนต์ Mali (ไทย + ละติน) สำหรับใช้ออฟไลน์ — SIL Open Font License
```

## ข้อมูล
เก็บใน `localStorage` ของเครื่องนั้นเท่านั้น ยังไม่ซิงก์ข้ามเครื่อง สำรองหรือนำเข้าเป็น JSON ได้ในหน้าตั้งค่า
เมื่อแก้ไฟล์แล้ว ให้เปลี่ยนค่า `V` ใน `sw.js` (เช่น `triply-v2`) เพื่อให้มือถือโหลดเวอร์ชันใหม่
